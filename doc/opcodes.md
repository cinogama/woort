# WooRT 指令集参考

本文档整理了 WooRT 虚拟机的所有指令，按功能分组。同一组内的指令功能相同，只是操作数宽度不同。

## 栈模型

```
sp      |                        | < 下一个值压入位置
        |~~~~~~~~~~~~~~~~~~~~~~~|
...     |                        |
        |_______________________|
sb      |_______________________| < 闭包捕获解包位置（如果是闭包）
sb + 1  |__ CALLWAY & BPOFFSET _|
sb + 2  |____ RETURN ADDRESS ___| < * 返回值存储位置
sb + 3  |_____ ARGUMENT 0 ______| < 变长参数数量（如果是变长参数函数）
sb + 4  |_____ ARGUMENT 1 ______|
```

## 操作数类型说明

| 符号 | 含义 |
|------|------|
| S8/S16/S32 | 有符号栈偏移（8/16/32位） |
| U8/U16 | 无符号偏移量（8/16位） |
| C16/C18/C24/C26/C32 | 常量区索引（16/18/24/26/32位） |
| N8/N10/N24/N32 | 计数/数量（8/10/24/32位） |
| T4/T8 | 类型标识（4/8位） |
| BA26 | 绝对跳转地址（26位） |

### 操作数属性

| 属性 | 说明 |
|------|------|
| R_ONLY | 只读操作数 |
| W_ONLY | 只写操作数 |
| R_M | 读操作数，对应的容器值将被修改 |

**重要**：所有指令的写操作总是发生在读操作之前。

## 字节码格式

每个字节码为 32 位，结构如下：

```
|__Main_Command(6bits)___|__Mode_(2bits)__|__A_(8bits)__ _|__B_(8bits)____|__C_(8bits)____|__EX_(32bits)__|
```

### 格式模板

使用 `woort_OpCodeFormal_cons` 宏构造字节码：

```c
/* 无额外操作数 */
woort_OpCodeFormal_cons(OP6, WOORT_OPCODE_NOP)

/* 带模式选择 */
woort_OpCodeFormal_cons(OP6_M2, WOORT_OPCODE_RET, 0)

/* 常量索引 (26位) */
woort_OpCodeFormal_cons(OP6_MABC26, WOORT_OPCODE_CALLNFP, 4)

/* MA10(10位) + BC16(16位) */
woort_OpCodeFormal_cons(OP6_MA10_BC16, WOORT_OPCODE_RESULT, 0, -3)

/* MAB18(18位) + C8(8位) */
woort_OpCodeFormal_cons(OP6_MAB18_C8, WOORT_OPCODE_LOAD, 0, 0)

/* M2(2位) + ABC24(24位) */
woort_OpCodeFormal_cons(OP6_M2_ABC24, WOORT_OPCODE_PUSHCHK, 0, 5)

/* M2(2位) + A8(8位) + BC16(16位) */
woort_OpCodeFormal_cons(OP6_M2_A8_BC16, WOORT_OPCODE_OPCIASMD, 0, -2, 0)

/* M2(2位) + A8(8位) + B8(8位) + C8(8位) */
woort_OpCodeFormal_cons(OP6_M2_A8_B8_C8, WOORT_OPCODE_OPIASMD, 0, -4, -3, -4)
```

## 2. 数据加载/存储

### 2.1 从常量区加载 (LOAD)

从常量区加载值到栈偏移处。

| 变体 | 格式 | 操作数 | 说明 |
|------|------|--------|------|
| LOAD | OP6_MAB18_C8 | C18, S8 | 常量索引18位，栈偏移8位 |
| LOADEX | OP6_MAB18_C8 + EX | C32, S16 | 常量索引32位，栈偏移16位 |

### 2.2 存储到常量区 (STORE)

从栈偏移处存储值到常量区。

| 变体 | 格式 | 操作数 | 说明 |
|------|------|--------|------|
| STORE | OP6_MAB18_C8 | C18, S8 | 常量索引18位，栈偏移8位 |
| STOREEX | OP6_MAB18_C8 + EX | C32, S16 | 常量索引32位，栈偏移16位 |

### 2.3 栈间移动 (MOV)

在栈位置之间复制值。

| 变体 | Mode | 操作数 | 说明 |
|------|------|--------|------|
| MOVLD | 0 | S16(源) → S8(目标) | 16位偏移到8位偏移 |
| MOVST | 1 | S8(源) → S16(目标) | 8位偏移到16位偏移 |
| MOVLDEXT | 2 | S32(源) → S16(目标) | 32位偏移到16位偏移 |
| MOVSTEXT | 3 | S16(源) → S32(目标) | 16位偏移到32位偏移 |
