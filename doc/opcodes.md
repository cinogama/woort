# WooRT 指令集参考

本文档整理了 WooRT 虚拟机的所有指令，按功能分组。同一组内的指令功能相同，只是操作数宽度（S8/S16/S32/C16/C18/C24/C32）不同。

## 操作数类型说明

| 符号 | 含义 |
|------|------|
| S8/S16/S32 | 有符号栈偏移（8/16/32位） |
| U8/U16 | 无符号偏移量（8/16位） |
| C16/C18/C24/C26/C32 | 常量区索引（16/18/24/26/32位） |
| N8/N10/N24/N32 | 计数/数量（8/10/24/32位） |
| T4/T8 | 类型标识（4/8位） |
| BA26 | 绝对跳转地址（26位） |

| 指令 | 说明 |

## 2. 数据加载/存储

### 2.1 从常量区加载 (LOAD)

从常量区加载值到栈偏移处。

| 变体 | 操作数 | 说明 |
|------|--------|------|
| LOAD | C18, S8 | 常量索引18位，栈偏移8位 |
| LOADEX | C32, S16 | 常量索引32位（EX字段），栈偏移16位 |

### 2.2 存储到常量区 (STORE)

从栈偏移处存储值到常量区。

| 变体 | 操作数 | 说明 |
|------|--------|------|
| STORE | C18, S8 | 常量索引18位，栈偏移8位 |
| STOREEX | C32, S16 | 常量索引32位（EX字段），栈偏移16位 |

### 2.3 栈间移动 (MOV)

在栈位置之间复制值。

| 变体 | 操作数 | 说明 |
|------|--------|------|
| MOVLD | S16(源) → S8(目标) | 16位偏移到8位偏移 |
| MOVST | S8(源) → S16(目标) | 8位偏移到16位偏移 |
| MOVLDEXT | S32(源) → S16(目标) | 32位偏移到16位偏移 |
| MOVSTEXT | S16(源) → S32(目标) | 16位偏移到32位偏移 |
